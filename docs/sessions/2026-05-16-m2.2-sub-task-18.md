### What shipped

**One public entry point**: `generate_report(*, db_path, run_id, output_path=None) -> Path`. Opens `replay_results.db` read-write, looks up the run, composes seven sections, writes the markdown file, returns the path. Caller owns nothing — the function manages the connection internally.

Output path default: `docs/reports/replay_<start_date>_run<run_id>.md` (start_date pulled from the run's `config_json`). Parent directory created if missing. Caller can override.

Failure semantics (Rule 18):
- Missing `db_path` → `FileNotFoundError` naming the path.
- Missing `run_id` → `ValueError` naming the requested id and listing the available ones.
- Empty run → every section renders a "no data" placeholder.
- Open run (`completed_at IS NULL`) → section 1 surfaces "run still open" rather than failing.

**Internal structure**: one private function per section (`_section_1_metadata`, `_section_2_decision_summary`, etc.) returning `list[str]` of markdown lines. `generate_report` orchestrates; `"\n".join(lines)` is the final write. Mirrors the `journal/eod_report.py` idiom.

### Sharpe ratio implementation

`_rough_sharpe(curve) -> float | None`. Compresses the 78+ ticks-per-day equity curve to one closing point per `trading_date` (last bar_et with that date prefix). Computes daily returns, then `mean(returns) / stdev(returns) * sqrt(252)`. Returns `None` when fewer than 2 distinct trading days are present (stdev undefined). The report wraps the number in a "short replay window; treat as directional only" caveat per the design doc's "rough, since replay window is short" warning.

### Max drawdown implementation

`_compute_max_drawdown(curve) -> (max_dd, max_dd_at)`. Standard running-peak walk: `dd = peak - equity` at each point; track the max. The portfolio side of the persistence layer already maintains `peak_equity` and `max_drawdown` on the SimulatedPortfolio itself, but recomputing from the curve avoids depending on those fields being correctly persisted (defensive — equity curve is the source of truth for the report).
