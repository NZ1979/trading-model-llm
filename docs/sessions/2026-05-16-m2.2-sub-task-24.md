### What shipped

The replay-harness trading-day enumerator now filters US market holidays, not just weekends. The pre-#24 `pd.bdate_range`-based weekday filter let holidays survive into `build_day_state`, where Polygon returned empty bars and the per-day try/except converted them into skipped `DayRunResult`s. Post-#24 the holiday never enters the loop in the first place — `run_replay` simply doesn't iterate it.

### Implementation

```python
from functools import lru_cache
import pandas_market_calendars as mcal

@lru_cache(maxsize=1)
def _nyse_calendar() -> mcal.MarketCalendar:
    return mcal.get_calendar("NYSE")


def _trading_days(start: date, end: date) -> list[date]:
    if end < start:
        return []
    sched = _nyse_calendar().schedule(start_date=start, end_date=end)
    return [ts.date() for ts in sched.index]
```

`mcal.get_calendar("NYSE")` builds an internal holiday calendar over a range of years; the `lru_cache(maxsize=1)` decorator memoizes it as a module-level singleton so multi-day replays don't rebuild it on each call. `cache_clear()` is available on the helper if a future test ever needs to swap exchanges (no caller today).

The `schedule()` call returns a DataFrame indexed by trading date with `market_open` / `market_close` columns. Half-day sessions (day-after-Thanksgiving, Christmas Eve when on a weekday) appear in the schedule with adjusted close times; the harness treats them as ordinary trading days, which is correct — the bar feed returns whatever bars exist and EOD-flatten at 15:55 remains the universal flatten point.
