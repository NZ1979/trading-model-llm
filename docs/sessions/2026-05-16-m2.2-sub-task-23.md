### What shipped

Section 1 of the replay-harness comparison report no longer says *"Cache hits/misses and per-tier wall-clock time are not yet persisted — deferred."* It now renders a real Cache stats table (per-tier hits / misses / hit-rate %) and a Phase timing block (total wall-clock + per-phase mean ms/day with day-count denominators) when the run's `summary_json` carries those fields.

### Data flow (end-to-end)

```
data/replay/driver.py::run_replay
  per day, on success path:
    _t0 = time.monotonic()
    day_state = await build_day_state(...)
    phase_ms["data_prep"] = (monotonic() - _t0) * 1000
    # same shape for tick_loop, fill_sim_llm, t3_labeling, base_pass
  DayRunResult(..., phase_durations_ms=phase_ms)

scripts/replay_with_llm.py::_run
  _replay_t0 = time.monotonic()
  results = await run_replay(...)
  total_wall_clock_ms = (monotonic() - _replay_t0) * 1000
  summary = _build_summary_json(results, wrapped,
      t3_budget=..., total_wall_clock_ms=total_wall_clock_ms)
  complete_run(conn, run_id=run_id, summary_json=summary)

scripts/replay_with_llm.py::_build_summary_json
  for phase in _PHASE_KEYS:  # data_prep, tick_loop, fill_sim_llm, t3_labeling, base_pass
    durations = [r.phase_durations_ms[phase]
                 for r in results
                 if r.phase_durations_ms and phase in r.phase_durations_ms]
    if not durations: continue
    payload[f"phase_{phase}_total_ms"] = round(sum(durations), 2)
    payload[f"phase_{phase}_mean_ms"]  = round(sum/len, 2)
    payload[f"phase_{phase}_n_days"]   = len(durations)
  if total_wall_clock_ms is not None:
    payload["total_wall_clock_ms"] = round(total_wall_clock_ms, 2)

sim/comparison.py::_section_1_metadata
  json.loads(summary_json) -> dict | None (defensive against
  None/empty/malformed/non-dict, WARNING log on malformed)
  _render_cache_stats(payload) -> "### Cache stats" + table or placeholder
  _render_phase_timing(payload) -> "### Phase timing" + bullets or placeholder
```

The mean denominator on each phase is the number of days that actually ran that phase (T3 disabled on a 5-day run with T3 enabled on 3 days → `phase_t3_labeling_n_days=3`, not 5). Absence is the signal; no zero-filling drags the mean down.

### Failure / partial-data handling (Rule 18)

| Input shape | Cache sub-block | Timing sub-block |
|---|---|---|
| `summary_json IS NULL` | *Cache stats not recorded for this run.* | *Phase timing not recorded for this run.* |
| Empty string | same as NULL | same as NULL |
| Malformed JSON | placeholder + WARNING logged | placeholder + WARNING logged |
| Parses to non-dict | placeholder + WARNING logged | placeholder + WARNING logged |
| Valid JSON, no cache keys | *No cached tiers in this run.* | renders timing if present |
| Valid JSON, no timing keys | renders cache if present | *No phase timing keys present in summary_json.* |
| T1 cache fields present, T2 absent | only T1 row in table | (independent) |
| Some phases present, others absent | (independent) | only present phases as bullets |
