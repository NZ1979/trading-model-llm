### What shipped

**Three new CLI flags:**

- `--base-portfolio` (store_true, default off) — opt-in toggle for running the base rule-based strategy in parallel on a second `SimulatedPortfolio`. Required for the comparison report's divergence section to have anything to compare against. Off by default because base evaluation is real work (every ticker, every tick, no pre-filter).
- `--base-require-walls-for-pullback` (BooleanOptionalAction, default False) — mirrors the new `ReplayConfig.base_require_walls_for_pullback` field from #17. Default False because walls are dormant in this fork (Databento canceled per PROJECT_BLUEPRINT § Vendor stack).
- `--skip-report` (store_true) — run the replay + persistence but skip `generate_report` at the end. Useful for batch runs.

**Updated `args_to_config`** to wire `base_require_walls_for_pullback` through to `ReplayConfig`. Previous flags unchanged.

**New `_replay_config_to_llm_config_dict(cfg)`** — bridges `ReplayConfig`'s flat fields to the nested `llm_config` dict shape `factory.build_tier_clients` expects:

```python
{"enabled": True,
 "t1": {"backend": cfg.t1_backend, "model_id": cfg.t1_model_id},
 "t2": {"enabled": cfg.t2_enabled, "backend": "anthropic", "model_id": cfg.t2_model_id},
 "t3": {"enabled": cfg.t3_enabled, "backend": "anthropic", "model_id": cfg.t3_model_id}}
```

T2/T3 backends hardcoded to `"anthropic"` — per design, only T1 is configurable across `qwen_local` / `anthropic` / `haiku_stand_in`.

**New `_setup_logging()`** — `logging.basicConfig(level=INFO, stream=sys.stderr)`, then forces `httpx` / `httpcore` / `aiohttp` / `anthropic` / `urllib3` to WARNING. Per **Rule 22**: httpx logs full request URLs at INFO by default; Polygon passes API keys as URL query params; without this gag, credentials would leak into stderr on every run. Same invariant the live `setup_logging` carries.

**New `_git_head_sha()`** — best-effort subprocess to `git rev-parse --short=7 HEAD` with a 5-second timeout. Returns the 7-char SHA or `None` on any failure (missing git, non-git directory, subprocess error). The result lands as `replay_runs.repo_sha` so the persisted DB carries reproducibility metadata.

**New `_build_summary_json(results, wrapped_clients)`** — aggregates per-day counts into a JSON blob stored on `replay_runs.summary_json`:

```python
{"n_days_total", "n_days_skipped",
 "n_llm_decisions", "n_base_decisions",
 "n_llm_fills", "n_base_fills",
 "n_llm_rejections", "n_base_rejections",
 "n_t2_escalations",
 # When a tier is wrapped in CachedLLMClient:
 "cache_t1_hits", "cache_t1_misses",
 "cache_t2_hits", "cache_t2_misses"}
```

The comparison report's section 1 can pluck cache stats from here once a future sub-task wires it; the field's intentional today.

**New `_run(cfg, args)` async body** — the full orchestration:

1. `open_fixture(cfg.sentiment_fixture_path)` for the historical sentiment SQLite (Rule-26 compliant — NOT trader-prod).
2. `build_tier_clients(_replay_config_to_llm_config_dict(cfg))` then wrap T1 + T2 in `CachedLLMClient`. T3 left raw because `run_replay` doesn't read `clients.t3` yet (Tier-3 pass is a deferred sub-task; wrapping would add dead code).
3. `cfg.replay_db_path.parent.mkdir(parents=True, exist_ok=True)` then `init_replay_db` then `start_run(conn, config=cfg, repo_sha=_git_head_sha())`.
4. Construct `SimulatedPortfolio(starting_cash=cfg.starting_cash, name="llm")`. When `args.base_portfolio` is set, also construct a `name="base"` portfolio.
5. `await run_replay(...)` with both portfolios + persistence threaded.
6. `complete_run(conn, run_id, summary_json=_build_summary_json(results, wrapped))`.
7. `generate_report(db_path=cfg.replay_db_path, run_id=run_id)` unless `--skip-report` is set. Path printed to **stdout** (pipeable); everything else goes to stderr (banners, log lines).
8. Connections closed in `finally` blocks (defensive — even on exception, no fixture or DB connection leaks).

**`main()` rewrite** — argparse → `_setup_logging` → `asyncio.run(_run(...))`. Three exit codes:

- 0 — success.
- 2 — `FileNotFoundError` (missing sentiment fixture, missing parent dir, etc.).
- 3 — `ValueError` / `NotImplementedError` (bad config, watchlist literal not yet wired through, etc.).

`--echo-only` bypasses `_run` entirely — prints the JSON config to stdout and returns 0 without touching any I/O. Useful for verifying flag parsing without side effects.
